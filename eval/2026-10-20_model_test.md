# 모델 품질 테스트

- 모델: govrule-4b (qwen3.5:4b Q4_K_M, num_ctx 8192, temp 0.2, nothink)
- 환경: RTX 3070 8GB / ollama 0.40.6 / PROCESSOR 100% GPU
- 일자: 2026-10-20

## 점수

| # | 항목 | 점수 | 비고 |
|---|---|---|---|
| 1-A | 한국어 자연스러움 | 5/5 | 문장 품질 우수 |
| 1-B | 내용 정확도 | 1/5 | 수의계약을 "저가 계약"으로 오인 |
| 2 | 공문 문체 전환 | 4/5 | 정상 |
| 3 | 법령 인용 형식 | 1/5 | 존재하지 않는 법률명 생성 |
| 4 | 환각 억제 | 0/5 | 금액/비율 전부 창작 |
| 5 | 지시 준수 | 5/5 | "확인 불가" 3토큰, 군더더기 없음 |
| 6 | 계산 정확도 | 5/5 | 5,500만원 정답 |

1-A와 1-B는 같은 질문에 대한 두 축의 평가다. 형식(문장)과 내용(사실)을 분리해 채점했으며, **이 둘이 정반대로 갈린 것이 이 테스트의 핵심 결과**다.

## 속도

- eval rate: 86~88 tokens/s
- prompt eval rate: 227~1,279 tokens/s (캐시 적중 시 최대)
- 짧은 응답 총 소요: 0.3~1.2초

## 핵심 발견

1. 환각이 "일관성 있게" 발생한다.
   temperature 0.2 + 구조화된 출력 형식이 결합해 틀린 답이 검증된 것처럼 보인다.
   1-B, 3, 4번은 동일한 오개념("수의계약=저가계약")에서 파생된 연쇄 오류.

2. 형식과 내용의 신뢰도가 분리된다.
   1-A는 5/5, 1-B는 1/5. 문장이 유창할수록 틀린 내용이 더 그럴듯해 보인다.
   사용자 입장에서는 오히려 위험하다.

3. 그러나 제약 지시는 정확히 따른다. (5번)
   모델의 "지식"은 신뢰 불가, "지시 준수"는 신뢰 가능.

4. 산술은 정확하나 의존하지 않는다. (6번)
   금액 계산은 Python 함수로 분리한다.

## 설계 결론

- 모델 내부 지식을 절대 답변 근거로 쓰지 않는다
- 검색된 조문 원문만을 컨텍스트로 주고, 없으면 "확인 불가"를 강제한다
- 모든 답변에 법령명 + 조문번호 + 시행일 + 원문 URL을 동반한다
- 금액 기준은 하드코딩하지 않는다 (시행령 개정 빈번)
